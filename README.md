## Fork's Intentions

This fork aims to migrate the source code from **Spring Boot 2.x / Java 8** to **Spring Boot 3.x / Java 17**, with the addition of testing components to ensure correct functionality after migration. 

The fork addresses incompatibilities between Spring Boot, Java, and certain dependencies. Additionally, some testing features were added to modules where they were not included originally, along with personal and minor improvements, such as applying coding guidelines and updating method calls.

Some of the aforementioned changes and enhancements include:

- Removed or replaced dependencies incompatible with Spring Boot 3
- Updated packages for Java 17
- Fixed broken dependencies
- Added testing features per module
- Added comments describing migration changes
- Applied coding guidelines (Sun checks and Google checks)

This fork is intended for **personal learning and self-study purposes**.
